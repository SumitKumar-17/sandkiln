title: sandkiln docs
description: Docs for sandkiln, a runtime for running untrusted or AI-generated code in hardware-isolated Firecracker microVMs.
---

sandkiln runs each sandbox as a Firecracker microVM with its own kernel, filesystem and network interface. You run the `sandkilnd` daemon on a Linux host with KVM and drive it from the JS/TS SDK, the Python SDK, the `kiln` CLI or plain HTTP.

## Start here

1. [Self-hosting quickstart](/getting-started/self-hosting): a running daemon in two commands.
2. Your first sandbox: [JS/TS](/getting-started/js), [Python](/getting-started/python) [CLI](/getting-started/cli) or [MCP](/getting-started/mcp) for AI agents.
