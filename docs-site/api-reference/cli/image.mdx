---
title: "kiln image"
description: Register, list, and delete custom rootfs images.
---

## `kiln image`

| Command | What it does |
|---|---|
| `create <id> <path>` | Register an already-built ext4 rootfs at `<path>` (a path on the daemon's own host, not a file upload) under `<id>`. Prints a warning that the guest agent can't be verified without root — see [Custom & managed images](/concepts/images). |
| `ls` | List registered images. |
| `rm <id>` | Delete a registered image. Refused while any sandbox, in-flight boot, or snapshot still references it. |

## Example

```bash
kiln image create node-lts-custom /home/t1000/images/node-lts-custom.ext4
registered node-lts-custom (warning: guest agent not verified -- run scripts/preflight-check.sh --root-checks --rootfs-image <path>)

kiln sandbox create --image node-lts-custom
ecc699a4-fa84-4bd2-9346-5e5c6b320e9e

kiln image rm node-lts-custom
error: image node-lts-custom is in use by sandbox ecc699a4-fa84-4bd2-9346-5e5c6b320e9e
```
