```bash
pip install sandkiln
```

Everything this SDK wraps is listed under [Sandbox](/api-reference/python-sdk/sandbox), [Image](/api-reference/python-sdk/image), [Drive](/api-reference/python-sdk/drive), and [Pool](/api-reference/python-sdk/pool). It matches the [JS/TS SDK](/api-reference/js-sdk/overview) method for method, including interactive `pty()` sessions, streamed background exec (`exec_stream()`, `attach_logs()`, `list_exec_streams()`) and `upload_dir()`/`download_dir()`. The WebSocket-based ones run on a small RFC 6455 client written on the standard library, so the package still has no runtime dependencies. Remote storage mounts are wrapped too (`sandbox.mount()`/`.list_mounts()`/`.unmount()`) — see [Drives](/api-reference/http-api/drives#remote-storage-mounts) for the full mechanics.

<Note>
Every class below also ships as an `asyncio`-native mirror — `AsyncSandbox`, `AsyncDrive`, `AsyncImage`, `AsyncPool` — with identical method names and arguments, just `async def` and awaited. They're deliberately separate classes rather than sync+async methods on one class, since a sync call in an async context blocks the event loop silently. `AsyncSandbox` exposes `tunnel()`, `pty()` and `attach_logs()` as awaitables that return async session objects (`AsyncPtySession`, `AsyncLogStream`).
</Note>

## Configuration

- **Daemon URL**: pass `base_url=` to any method, or set `SANDKILN_DAEMON_URL`. Defaults to `http://127.0.0.1:7777`.
- **Auth**: pass `auth_token=`, or set `SANDKILN_AUTH_TOKEN`. Omit entirely for an unauthenticated local daemon.

```python
import os
from sandkiln import Sandbox

# Explicit per-call config...
sandbox = Sandbox.create(base_url="https://daemon.internal:7777", auth_token=os.environ["SANDKILN_TOKEN"])

# ...or set both as environment variables once and omit them everywhere:
# SANDKILN_DAEMON_URL=https://daemon.internal:7777
# SANDKILN_AUTH_TOKEN=...
same_sandbox = Sandbox.create()
```

## Daemon status

`get_status(base_url=None, auth_token=None)` returns host health and capacity as a frozen `DaemonStatus` dataclass; `sandkiln.astatus.get_status` is the `asyncio` version. See [`GET /status`](/api-reference/http-api/status).

```python
from sandkiln import get_status

status = get_status()
if status.warnings:
    print(status.warnings)
```
