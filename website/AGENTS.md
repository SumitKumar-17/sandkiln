# AGENTS.md — website/

Read root `AGENTS.md` first. This is the **product page and nothing else**:
one Astro page for someone deciding whether sandkiln is for them. Everything
technical (reference, architecture, internals, latency research, the
engineering blog) lives on the docs site, `docs-site/`, live at
https://sandkiln.mintlify.site/. The two sites are the whole public surface;
see `docs/documentation-plan.md` for what belongs where. Links from here to
the docs are absolute URLs (the `DOCS` constant).

## Structure

- `src/pages/index.astro`: the only page: headline, one paragraph with inline
  links, the install box with a copy button, a real terminal session.
- `src/layouts/BaseLayout.astro`: head, fonts (Geist for headings, JetBrains
  Mono for text), social card (`public/og.png`).
- `src/components/Header.astro`, `Footer.astro`.
- `src/styles/global.css`: the whole design system: dark only, one link
  colour, hairlines, one column. Add a token there or nowhere.
- `src/data/numbers.json`: **generated**, the only numbers the page shows.
- `public/`: `favicon.svg` and `mark.svg` (generated: a kiln arch holding a stack of sand
  grains), `product.svg` (generated), `og.png` (generated by
  `scripts/dev-tools/make-og.sh`).

## Rules

- **Stay one page, and keep it plain.** A section that needs depth becomes a
  docs page and a link here, not a new route or a new block.
- **No hand-typed numbers or copies.** A fact written in two places goes
  stale in one of them. Numbers come from `src/data/numbers.json`, generated
  by `scripts/dev-tools/make-numbers.py` from `examples/benchmark-suite/results/`.
  The session image comes from `docs/images/product-session.txt` via
  `scripts/dev-tools/make-product-image.py`; the logo and favicon from
  `scripts/dev-tools/make-logo.py`. Never edit generated files by
  hand; `scripts/dev.sh docs-check` fails when they are stale.
- Never name a competing platform here.

## Base path and Node version

GitHub Pages serves this as a project page (`sumitkumar-17.github.io/sandkiln/`);
a mirror serves it at a domain root. `astro.config.mjs` reads `ASTRO_BASE`
(default `/`), set to `/sandkiln` only by `deploy-pages.yml`; `ASTRO_SITE` sets
the origin used for the social-card URL. `compressHTML` is off on purpose: the
minifier strips the space before an inline link. Astro 7 needs Node >=22.12.

## Verifying a change

`npm run build` passing is necessary, not sufficient. Look at it: build, serve
`dist/`, and take a screenshot at 1280 and 390 pixels wide
(`google-chrome --headless=new --screenshot`, on the dev box).

## Deployment

GitHub Pages (`deploy-pages.yml`, every push to `main` touching this
directory) is the source of truth; `vercel.json` makes the same build
deployable elsewhere. The docs site deploys separately from `docs-site/`
through Mintlify's own GitHub integration.
